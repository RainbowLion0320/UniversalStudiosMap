# 北京环球影城可视化路线规划

目标：在地图上选择想玩的项目，结合园内步行、排队、演出时间和休息安排，形成可调整的游玩路线。

当前阶段：资料调研与数据可用性验证，尚未实现地图应用。

- [开源项目与数据调研](docs/research.md)：选型、实测覆盖、限制和下一步。
- [数据来源说明](data/README.md)：来源、署名和本地快照规则。
- `scripts/fetch_beijing.py`：Python 3 标准库脚本，无额外依赖。
- `data/beijing.overpassql`：北京环球附近的步行道路查询，带道路节点和几何。

## 获取本地数据

```sh
python3 scripts/fetch_beijing.py
```

每次运行抓取园区信息、项目坐标、实时状态、营业日历、备用排队接口和 OSM 道路。
结果在 `data/local/<UTC 时间>/`，已从 Git 排除；每个来源有抓取时间，失败记录在 manifest，部分失败时脚本返回非零退出码。
公共 Overpass 服务可能超时；可稍后重试，不能把失败等同于没有道路。
