# 环球漫游 · 北京环球影城

用一张 Low Poly 微缩园区地图，挑选项目、安排游玩顺序和估算一天的时间。本地应用，Three.js 渲染 Blender 模型，Node/Vite 提供园区数据读取与刷新。

## 启动

需要 Node.js 22.12+ 和 Python 3（仅首次抓取数据时需要）。

```sh
npm install
npm run data:fetch  # 已有 data/local/ 快照时可跳过
npm run dev
```

打开 http://127.0.0.1:5173 。此仓库所在机器已保留可用快照。

```sh
npm test
npm run build
npm run preview    # http://127.0.0.1:4173
```

`preview` 同样提供本地数据接口；单独把 `dist/` 放到纯静态服务器不能刷新或读取园区数据。

## 已实现

- Blender 原生建模的 Low Poly 园区：真实 OSM 平面、建筑、水面、步道，七大分区地标与切面植被。
- 3D 旋转、缩放、平移、俯视、全景模式；地理坐标项目标记与路线同步投影。
- 44 个项目／演出，中文名、搜索、分类与分区筛选、地图详情、加入或移除行程。
- 拖动或上下按钮调整顺序；保留第一站、按已知步道距离排序，只有比原顺序短时才采用。
- 步道图最短路径、步行时长、默认与手动排队、体验时长、休息预留、演出场次、闭园时间提示。
- 新鲜度门槛：当天且抓取不超过 15 分钟才可使用实时排队；未来日期和旧快照使用显式估算。缺失排队不是零分钟。
- 浏览器本地保存、完成打卡、Markdown 攻略导出、排队与营业日历刷新。
- 手机以「选项目 / 看地图 / 我的一天」切换。

## 路线的实际范围

第一站是起点，不含入园和离园步行。绿色线沿 OSM 步道计算，棕色虚线是景点坐标与最近步道节点之间的估算连接，不代表已确认的入口。离步道超过 100 米或图不连通时，不绘制假路线、不补造行走时间，会提示估算不完整。

初始路网经过滤有 578 个节点、590 条边记录；排除私有/禁行、室内、步行区域面等不适合直接推断的通道，可选择避开已标记台阶。尚未逐一确认入口、临时封路和完整无障碍路线。路网的最短路径是算法结果，实际园内通行需现场核对。

体验时长与中文展示名为本地编辑数据，非官方时长保证；演出缺少场次时提示待确认。休息时间统一放在行程末尾。完成标记不扣减原行程用时。自动排序只考虑已知步行距离，不保证排队与演出综合最优。

## 数据与网络

应用读取 `data/local/` 下最新可用的各来源快照。ThemeParks.wiki 原始响应不提交 Git，按来源记录抓取时间；刷新失败保留缓存。OSM 建模源数据已收录在 `art/source/`，也用于路网缺失时的回退。无本地项目数据时会给出抓取指引。

数据展示署名 Powered by ThemeParks.wiki；地图 © OpenStreetMap contributors。模型与网页不使用官方照片作为纹理。详细条件见数据与模型说明。

网页不加载外部瓦片或远程字体；已有模型和快照时，探索与规划不依赖外网。没有 Service Worker，不提供离线安装承诺；刷新排队数据需要联网。

## 安卓 APK

已增加 Android 工程和离线打包脚本，支持横屏 / 竖屏、系统返回键、系统分享与本机自动保存。首页采用地图优先布局，项目清单与行程按需展开。

```sh
npm run android:release
```

安装包位于 `output/release/universal-wander-1.0.0.apk`。环境配置、签名备份与使用说明见 [docs/android.md](docs/android.md)。
