环球漫游首个公开版本：北京环球影城 Low Poly 地图与离线行程规划。

### 下载与安装

- 下载 `universal-wander-1.0.0.apk`，Android 8.0+，需要支持 WebGL 2 的 Android System WebView。
- APK 为正式签名 release 构建。无需连接开发电脑、无需账号；可覆盖此前由本项目相同密钥签名的本地 1.0.0 安装包。
- `.apk.sha256` 用于完整性校验，`THIRD_PARTY_NOTICES.md` 说明素材和依赖许可。GitHub 自动提供 Source code zip / tar.gz。

### 功能

- Blender Low Poly 三维园区，旋转、缩放、平移、俯视。
- 44 个项目/演出的离线展示清单，搜索、选项目、路线规划、时间估算与完成记录。
- 精简的三入口界面，横屏/竖屏自适应，自动保存及 Android 系统分享。
- 基于 OSM 步道计算路径；排队与演出联网更新，未来日期使用估算。

### 验证与限制

11 项算法测试通过；Android 16 ARM64 模拟器验证离线全新安装、旋转、返回键、系统分享和覆盖安装保留数据。尚未实测实体手机。地标是艺术化模型，入口、封路和场次仍需现场核对。
